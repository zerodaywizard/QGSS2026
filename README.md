# QGSS2026

IBM Qiskit Global Summer School - 2026 Lab Assignments

## Overview

This repository contains lab assignments and materials for the IBM Qiskit Global Summer School 2026 program.

## Contents

- **Jupyter Notebooks**: Lab assignments and exercises in Jupyter Notebook format

## Prerequisites

- Python 3.8+
- Jupyter Notebook
- Qiskit

## Installation

```bash
pip install qiskit jupyter
```

## Running the Notebooks

1. Clone this repository
2. Navigate to the repository directory
3. Launch Jupyter Notebook:
   ```bash
   jupyter notebook
   ```
4. Open the desired notebook and run the cells
